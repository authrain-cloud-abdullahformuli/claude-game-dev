# AGENTS.md — Guidelines for Claude Code Game Development

Welcome to **Claude Game Dev**, the comprehensive library of game development patterns, prompts, and architecture for Claude Code.

## Architecture
- `docs/`: 13 specialized domains spanning core concepts, physics, AI, audio, networking, UI/UX, game engines, performance optimization, and testing.
- `tools/meta-prompting-framework/`: Execution engines, agents, and meta-prompts for automated game system scaffolding.
- `plugins/`: Ready-to-use plugins across 66 development categories.

## Agent Workflows
1. Consult `docs/` for specific game design patterns (ECS, state machines, spatial partitioning, game loops).
2. Use verified prompt templates in `tools/meta-prompting-framework/meta-prompts/` to build systems step-by-step.
3. Validate mechanics iteratively with playtesting loops.
